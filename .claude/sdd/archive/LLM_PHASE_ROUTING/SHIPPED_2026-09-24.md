## Resumo

Manifesto único `PHASE_MODEL_ROLES.toml` declara, por fase do SDD, o papel OMP, o alias Claude e o effort Codex. O OMP resolve papel → modelo via `task.agentModelOverrides` (trecho gerado por `make omp-roles`, colado pelo usuário). `/design` e `/ship` delegam ao agent da fase; as fases interativas continuam na sessão. Templates SDD ganham a linha **Gerado por**. `plugin/agents/` é achatado para o OMP descobrir os agents. Isso fecha a lacuna em que o `model:` do agent era ignorado porque o comando rodava inline.

## Lições Aprendidas

### Processo

- A delegação no OMP é instruída no prompt, **não enforced**: com `gpt-6-astra` (`@plan`) como modelo da sessão, `/ship` rodou os Steps 1–8 inline (fallback, corretamente registrado em **Gerado por**). 1 de 2 execuções delegou.
- Commitar depois do `/eval` move o `HEAD` → `verify` retorna `STALE_COMMIT`. Manter o recibo fora do commit até o `/ship`, ou rerodar `/eval`.

### Técnico

- O config correto do OMP é `~/.omp/agent/config.yml`. `config.yml.lock` é um lock de 0 bytes — não editar.
- O cache do marketplace do Claude Code ficou no commit antigo porque a versão do plugin **3.4.1 não mudou**: `claude plugin update` diz "already latest". Mudança de layout do plugin exige bump de versão.
- O modelo default da sessão (`deepseek`) retornou `402 Insufficient Balance`; os testes humanos precisaram de `--model` explícito.

### Comunicação

- Os nomes de slash command de plugin incluem a pasta: `/agentspec:workflow:design`, não `/agentspec:design`.

### Ferramentas e Bibliotecas

- `tomllib` + `make omp-roles` (`phase_routing.py --print-omp-overrides`): o usuário cola o trecho; o repositório nunca lê nem escreve `~/.omp`.

## Recomendações para Trabalhos Futuros

| Área | Recomendação |
|------|--------------|
| Plugin | Bumpar a versão do plugin sempre que o layout (`plugin/agents` achatado) mudar; senão o marketplace não atualiza |
| OMP | Não tratar `config.yml.lock` como config; overrides só em `~/.omp/agent/config.yml` |
| Eval/Ship | Não commitar o recibo até depois do `/ship`, para evitar `STALE_COMMIT` |
| Testes manuais | Abrir o OMP com `--model` explícito (`@plan` / `@slow` / `@smol`); o default pode estar sem saldo |
